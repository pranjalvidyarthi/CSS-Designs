# 🧱 CSS Designs

A tiny but powerful collection of **CSS utility classes and micro components** designed for rapid styling and simple, reusable layouts.

---

## 🌟 Features

- Lightweight CSS utilities
- Reusable design snippets
- No JavaScript — pure CSS
- Great for rapid prototyping and micro UI work

---

## 📁 Project Overview

Each CSS file in this repo contains a set of utility classes or micro design patterns you can include in your project.

Example utilities include:

```
Utility | Purpose
--------|---------
Margin & Padding | Spacing utilities
Text Styles | Typography helpers
Containers | Layout helpers
Buttons | Ready-to-use button styles
Cards | Simple card UI
```
---

## 🚀 How to Use

### 1️⃣ Clone the Repo

```bash
git clone https://github.com/pranjalvidyarthi/CSS-Designs.git
```

### 2️⃣ Include the CSS File

Link the CSS file in your HTML:

```html
<link rel="stylesheet" href="<filename>.css">
```

### 3️⃣ Apply Utility Classes

Use the utility classes in your HTML elements:

```html
<div class="container center padding-md text-bold">
  Hello, CSS!!
</div>
```
